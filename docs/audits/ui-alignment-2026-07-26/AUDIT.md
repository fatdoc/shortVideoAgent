## 5. 全局 UX 与视觉风险

### P0 · 结构性

1. **全局壳层与参考图不一致**：浅色侧栏、全局搜索、团队 / 用户区必须统一修正。
2. **案例 / 项目入口能力缺失**：当前单 Demo 让 Dashboard 无法达到参考图的信息密度。
3. **真实视觉资产不足**：头像、品牌图、视频 / 图片缩略图大量由文字或简单占位替代。
4. **首屏信息利用率低**：大卡片和纵向堆叠让关键内容落到折叠线下。

### P1 · 一致性与可用性

1. 统一卡片圆角、边框、阴影、间距和 12/14/16/20px 字号层级。
2. 状态不能只依赖蓝 / 绿 / 橙颜色，需要保留文字或图标。
3. 1440×900 必须验证无横向裁切；1672×941 用于忠实对照原图。
4. 键盘焦点、屏幕阅读器标签和缩放重排无法仅从截图确认，需在 C7 做专项验证。
