# GLOSSARY · 统一术语

| 术语 | 权威定义 | 禁止混用 |
|---|---|---|
| 租户 Tenant | 购买并使用平台能力的隔离组织 | 品牌、门店、项目 |
| 渠道组织 | 销售或分销平台产品的组织节点 | 普通部门 |
| 企业客户 | 渠道链路末端或平台直销的使用方租户 | 代理商 |
| AI 视频额度 | 平台内部可计价、可冻结、可扣减的生产单位 | 上游 token、人民币余额 |
| Capability | 可售卖或可授权的原子能力 | 页面功能 |
| Product | 面向客户的产品定义 | 单次订单 |
| SKU | 产品、规格、额度和有效期的可购买组合 | 模型名称 |
| PriceBook | 针对渠道或客户群的价格表 | 上游成本表 |
| Wallet | 某组织持有额度的账户容器 | 银行账户 |
| CreditLedger | 额度增加、冻结、扣减、释放和调整的不可篡改流水 | 可覆盖余额字段 |
| AgentTemplate | 本地生活、老板 IP、电商等业务流程模板 | 独立租户 |
| Campaign | 一次营销活动 | 单个生成任务 |
| Project | 一次视频生产工作的聚合根 | 租户 |
| StoryCanvas | 分镜、引用、生成、素材、时间线和导出的媒体生产平面 | 整个平台 |
| Control Plane | 租户、产品、交易、品牌和权限所在的 SaaS 控制平面 | 生成供应商 |
| Production Plane | StoryCanvas 媒体生产平面 | 钱包和结算系统 |
| Upstream API Key | 平台调用模型供应商的服务端密钥 | 客户可见 Key |
| Platform API Key | 平台签发给下游的受限访问凭证 | 上游供应商密钥 |
