# ROLE WORKBENCHES · 角色工作台设计

## 核心原则

系统不是给每个角色开发一套独立应用，而是使用统一账号体系和四类核心工作台，通过组织、角色、套餐和数据范围动态组合功能。

```text
可见工作台功能
= 组织类型
∩ 成员角色
∩ 已购套餐/能力
∩ 数据权限范围
```

同一个用户可以加入多个组织并拥有不同身份。切换组织或身份后，菜单、指标、余额、数据范围和可执行操作必须同步变化。

## 一、平台管理工作台

适用角色：

- 平台超级管理员
- 平台运营
- 平台产品管理员
- 平台财务
- 平台风控

主要功能：

- 租户与渠道组织
- 代理层级
- 产品、Capability、SKU 和 PriceBook
- 额度发行、钱包和账本
- 订单、退款、结算和对账
- 模型供应商、成本和任务质量
- 平台 API Key 和审计
- 全局风险与经营指标

## 二、渠道代理工作台

适用角色：

- 总代理
- 一级代理
- 二级代理

三个层级共用一套渠道工作台，通过层级深度、价格表和数据范围控制差异，不重复开发三个系统。

主要功能：

- 我的额度和已冻结额度
- 产品采购与可售套餐
- 下级渠道和企业客户
- 额度分配
- 销售订单
- 批发价与客户价
- 差价收益
- 对账单
- 客户用量

限制：

- 只能查看自己组织及被授权下级的数据。
- 二级代理默认不能继续发展下级代理。
- 不显示平台上游成本和供应商密钥。

## 三、企业客户工作台

适用角色：

- 企业老板
- 企业管理员
- 市场负责人
- 内容运营
- 门店运营
- 企业财务查看人员

主要功能：

- 经营概览
- 套餐和剩余额度
- 品牌与门店
- 场景 Agent
- 视频项目和 Campaign
- 品牌大脑
- 脚本、分镜和成片
- 素材资产
- 团队成员
- 使用明细和续费

数据范围：

- 企业老板和管理员可查看企业整体。
- 门店运营只查看被授权门店。
- 市场和内容角色默认不能调整价格或管理充值。

## 四、媒体生产工作台

适用角色：

- 内容策划
- 脚本编辑
- 分镜师
- AI 视频操作员
- 剪辑师
- 内容审核员

主要功能：

- Creative Brief
- 品牌事实、禁用词和引用
- 脚本版本
- 分镜画布
- 角色、场景和连续性记忆
- 图片和视频生成
- 生成任务与失败重试
- 素材资产
- 时间线、预览和导出
- 内容风险与成片 QA

StoryCanvas 是媒体生产工作台的核心生产平面，但不承担企业钱包、代理关系和客户价格。

## 五、API 开发者控制台

API 客户属于扩展工作台，商业 MVP 后按需要启动。

主要功能：

- 平台 API Key 创建、轮换和禁用
- 接口文档
- 调用记录和错误日志
- Webhook
- 任务和额度消耗

客户永远不能看到上游供应商 API Key。

## Demo 首期角色

老板 Demo 优先实现四个入口：

1. 平台管理员
2. 代理商
3. 企业客户
4. 媒体生产

其他角色先通过身份切换和权限差异表达，不为每个角色重复开发完整页面。
