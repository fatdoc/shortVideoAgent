# C5 招聘说明书 · StoryCanvas 与媒体生产引擎负责人

## 使命

在现有 StoryCanvas 成果上增量精进，形成可被商业 SaaS 调用的专业媒体生产平面。

## 核心职责

脚本、分镜画布、角色/场景引用、连续性记忆、图片/视频任务、供应商适配、资产、时间线、编辑和导出。

## 不负责

租户层级、客户钱包、产品价格、代理分润和商业后台。

## 强制原则

不 reset、不 checkout 丢改动、不整体重建；优先当前源码和最新设计 QA；上游 Key 只留服务端。

## 第一阶段产物

能力盘点、保留/改造清单、集成边界、缺口和风险、Demo/商业 MVP/完整管线三阶段计划。
