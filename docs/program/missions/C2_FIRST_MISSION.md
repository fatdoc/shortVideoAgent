# C2 首轮任务书 · 场景产品与能力目录 v0.1

## 任务

1. 将原 PRD 功能拆成共享生产能力、场景 Agent、商业能力三层。
2. 为基础生成、本地生活、老板 IP、电商、数字人、API 能力包定义输入、输出和价值。
3. 设计 Product、Capability、SKU、Entitlement 的关系提案。
4. 以海底捞三里屯形成从 Brief 到交付的业务案例。
5. 区分 Demo 必需、商业 MVP 必需和后续能力。

## 输出

场景地图、能力目录、产品包矩阵、Agent I/O、优先级和 Request。

## 验收

不得把全部 PRD P0 原样搬入首版；不得决定账本和底层 API。
