# C1 首轮任务书 · 租户与渠道模型 v0.1

## 必读

项目章程、共同记忆、术语、角色边界、原始 PRD 中租户/代理/权限相关内容。

## 任务

1. 列出直销、总代理、一级代理、二级代理、企业分配、API 客户和白标六种场景。
2. 区分 Tenant、ChannelOrganization、Brand、Store、Project。
3. 设计组织树、成员关系、角色权限和可见数据范围。
4. 说明首版层级上限、禁用循环挂靠和渠道退出/转移规则。
5. 标出涉及财务、法务和用户决策的待决问题。

## 输出

`租户渠道设计 v0.1`、角色权限矩阵、关系图、示例链路、Request。

## 验收

不能把品牌/门店当租户；不能以拉人头数量产生收益；不写钱包算法。
