# C6 首轮任务书 · 老板演示黄金路径 v0.1

## 任务

1. 设计 10—15 分钟演示节奏和讲解词。
2. 从角色进入、选择品牌、选择 Agent、品牌大脑、脚本、StoryCanvas、生成、额度到成片形成页面地图。
3. 列出每一步的输入、操作、状态变化、业务价值和失败兜底。
4. 明确 SaaS 与 StoryCanvas 的跳转方式和视觉连续性。
5. 复用海底捞三里屯、C1—C8 和现有 UI，不另起 Demo 主数据。

## 输出

Demo Storyboard、页面地图、关键交互清单、断点和 Request。

## 验收

不把未决商业规则伪装成已实现；不以静态截图代替关键操作。
