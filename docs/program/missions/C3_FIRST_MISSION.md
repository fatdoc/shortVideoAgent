# C3 首轮任务书 · 额度、价格与结算 v0.1

## 任务

1. 定义客户可理解的 AI 视频额度，不直接使用供应商 token。
2. 建立上游成本、平台结算价、渠道批发价、客户零售价、活动价五层概念。
3. 设计 Wallet 与 append-only CreditLedger。
4. 定义充值、赠送、转拨、冻结、扣减、释放、退款、过期和人工调整。
5. 设计批发差价优先的渠道收益模型，并列出后续佣金扩展点。
6. 用三个完整算例说明成功、失败和跨级销售。

## 输出

商业计量模型、状态机、算例、风险和 Request。

## 验收

余额变化必须可追溯；生成失败必须有释放规则；不开发画布。
