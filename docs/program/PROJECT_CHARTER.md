# PROJECT CHARTER · 项目章程

## 一句话定位

面向渠道商和企业客户的 AI 视频产能商业化平台：用场景 Agent 提高视频生成额度的业务价值，用 StoryCanvas 完成专业媒体生产，用租户、套餐、钱包和结算完成商业闭环。

## 商业本质

- 核心商品是平台内部的“AI 视频额度”，不是向客户暴露上游原始 token。
- 本地生活、老板 IP、电商等 Agent 是能力包装和溢价来源。
- 上游模型 API Key 由平台统一托管；下游如开放 API，只发受限的平台 Key。
- 首版渠道结构允许配置，但实施上限为：平台 → 总代理 → 一级代理 → 二级代理 → 企业客户。
- 首版优先采用预付额度和批发差价，不优先实现复杂比例佣金。

## 当前目标

先完成一条老板能够顺畅演示、能够讲清商业价值和生产流程的前端 Demo，再进入商业 MVP 和真实媒体生产强化。

## 当前 Demo 黄金路径

海底捞三里屯案例 → 选择本地生活 Agent → 品牌大脑事实与规则 → 生成/编辑脚本 → 创建分镜生产单 → 进入 StoryCanvas → 调整镜头与引用 → 模拟或真实生成 → 回传素材和用量 → 展示额度扣减 → 导出成片。

## 当前阶段允许

- 前端 + Mock。
- 本地案例和预置数据。
- 模拟钱包、任务状态和成本。
- 对 StoryCanvas 做增量精进。
- 为真实后端预留合同，但不建设复杂基础设施。

## 当前阶段不做

- 真实资金清结算和打款。
- 无限制代理层级。
- 以拉人头数量计算收益。
- 完整生产级微服务改造。
- 所有模型供应商同时接入。
- 推翻或重写现有 StoryCanvas。
- 为了“技术完整”扩张非关键边角。

## 成功标准

- 老板能在 10—15 分钟内讲清客户、产品、额度和生产闭环。
- SaaS 与 StoryCanvas 的边界清晰，接口合同可版本化。
- 每项额度变化可解释到订单、任务或人工调整。
- 生成资产可追踪来源、模型、提示词、引用和任务。
- 九个员工不重叠修改核心文件，不靠聊天记忆推进。
