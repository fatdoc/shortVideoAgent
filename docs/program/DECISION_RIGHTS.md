# DECISION RIGHTS · 决策权限

| 决策类型 | 主提案 | 必须会签 | 最终批准 |
|---|---|---|---|
| 项目范围和阶段目标 | C0 | 相关员工 | C0 / 用户 |
| 租户、渠道、代理规则 | C1 | C3、C4 | C0 |
| 场景 Agent、能力和产品包 | C2 | C3、C6 | C0 |
| 价格、额度、钱包和结算 | C3 | C1、C4 | C0 |
| 控制平面数据和 API | C4 | C1、C3、C7 | C0 |
| StoryCanvas 架构和媒体管线 | C5 | C4、C7 | C0 |
| 跨系统 UX 和 Demo 路径 | C6 | C2、C4、C5 | C0 |
| Gate 放行建议 | C7 | 交付员工 | C0 |
| 对外材料发布 | C8 | 事实 Owner | C0 / 用户 |

## 必须升级给 C0 的事项

- 修改共同 ID、状态机或额度语义。
- 同时影响两个以上员工的文件。
- 引入新基础设施或第三方供应商。
- 改变商业模式、渠道收益或客户承诺。
- 涉及授权、合规、资金、版权和个人信息。
- 需要删除、回滚或替换现有成果。

## ADR 规则

影响两个以上领域、持续超过一个 Wave 或难以回滚的决策，必须使用 `templates/ADR_TEMPLATE.md`。
