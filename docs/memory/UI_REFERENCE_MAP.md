1. 实现页面前先对照对应编号参考图
2. 还原：布局结构、信息层级、主色、卡片密度
3. 不要求像素级 1:1，但风格必须一致
4. 文件名含空格与括号，代码中引用需注意
5. docs/ui 仅放说明，不复制大图
