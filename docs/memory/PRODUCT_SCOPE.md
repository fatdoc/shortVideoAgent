# 产品范围 · PRODUCT SCOPE

## 一句话

短视频营销 Agent 前端可交互 MVP：用 Mock 演示从 Brief 到导出的完整生产链路。

## In Scope（首期）

- 6 个核心页面的前端交互
- 统一 Demo 项目数据贯穿全流程
- 模拟 AI 生成 / 上传 / 质检 / 导出
- 本地状态持久化（LocalStorage）
- 设计系统与公共布局
- 单元测试与基础 E2E 冒烟

## Out of Scope（明确不做）

- 真实账号体系与权限
- 真实后端、数据库、对象存储
- 真实 LLM / ASR / OCR / FFmpeg
- 专业非线编、关键帧、数字人、声音克隆
- 平台自动发布与真实投放归因
- 原生 App
- 计费与多租户隔离

## 用户价值（Demo）

1. 让业务方看清「AI 短视频工作台」如何跑通
2. 让研发按模块并行，不互相踩踏
3. 为后续真实接入预留 domain / service 边界

## 成功标准（产品）

- 主流程可点通
- 数据跨页一致
- 刷新不丢核心状态
- UI 风格统一，接近参考图
- 可对内演示
