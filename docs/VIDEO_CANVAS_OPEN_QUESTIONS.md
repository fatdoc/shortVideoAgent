# 视频画布仍无法确认的问题

## 1. 商业与用户

1. 真实客户是企业市场部门、门店运营、广告公司还是平台内部制作团队。
2. 是否已有真实总代理、一级代理、二级代理账号和合同。
3. 代理采购价、销售价、佣金比例、账期、结算和退款规则。
4. AI_VIDEO_CREDIT与人民币、供应商成本、视频时长和分辨率的换算。
5. 是否有真实用户正在使用旧 Toonflow链或旧50188子窗口。

## 2. 运行与部署

1. 生产环境 StoryCanvas API和根 SaaS如何部署、鉴权和互联。
2. 当前机器应使用哪个 SQLite；代码解析路径曾指向其他 worktree。
3. API启动自动 migration是否允许在验收环境执行。
4. 当前有效 Grant是否由控制面动态重签。
5. 本机 `/media/d1/demo-local-001-fallback-synthetic-v1.mp4`是否真实存在和可播放。

## 3. 模型与费用

1. 哪些供应商账户已开通、余额和地域限制。
2. 各模型真实质量、成功率、时延和单次成本。
3. 真实失败任务是否退还商业额度。
4. canonical未来是否要接回真实生成，还是长期只做合同演示。
5. OpenStoryline/FireRed是否已部署并在线。

## 4. 数据与安全

1. 生产数据库中的项目、任务、记忆、孤立资产和Schema漂移现状。
2. 真实用户、组织、订单、支付和发票数据是否另有后端。
3. WebSocket `isolationKey`是否始终与projectId和tenantId强绑定。
4. API路由是否在网关层补充了项目所有权检查。
5. 明文Vendor Key是否已经在实际数据库中存在。

## 5. 画布、记忆和分镜

1. 画布布局是否曾有服务器保存实现或外部前端实现。
2. 角色资产Workspace是否计划恢复导航入口。
3. `sc_edit_sessions/edit_commands/timeline_versions`是否有外部消费者。
4. 真实世界事件和Continuity Review是否由其他服务写入。
5. 成功Task/Asset如何获得最终 `mediaUrl`并显示在画布。
6. StoryboardShot与生成视频的产品期望是一一对应还是多版本选择。
7. 旧 `o_agentWorkData.flowId/o_imageFlow`与当前节点的完整映射。

## 6. 交付和合规

1. 最终支持的画幅、时长、编码、容器、码率和音频策略。
2. 水印、商用授权、版权、肖像权、音乐授权规则。
3. 是否需要导出剪映、Premiere或其他剪辑工程。
4. 人工审核角色、审核队列、驳回、补偿和审计签名。
5. 团队协作、评论、审批人和项目共享范围。

## 7. 3D白模研究问题

1. 白模是上传GLB/FBX、图片、视频还是外部链接。
2. 白模属于Scene、Reference Asset还是独立Shot Input。
3. 相机轨迹需要何种坐标系、焦距、帧率和时间编码。
4. 预演视频是否替代分镜图或只是生成参考。
5. 供应商是否支持3D、Depth、Camera Path或Control输入。
6. 3D产物如何进入Asset Receipt、版权和成本账本。

这些问题不能仅靠当前代码确定，不应在答案未知时启动重构。
