# 统一验收标准 · ACCEPTANCE

## 所有员工

- 不越权、不覆盖、不回滚既有成果。
- 事实、提案和未决事项明确区分。
- 更新自己的 STATUS、PLAN、HANDOFF、REQUESTS、CHANGELOG。
- 跨域变化有 Request；长期决策有 ADR。
- 输出能被下游直接消费，不只给泛泛建议。

## 文档/设计交付

- 术语与 `GLOSSARY.md` 一致。
- 对象、状态、Owner 和边界完整。
- 至少包含主路径、失败路径、风险和未决问题。
- 不承诺未实现能力。

## 代码交付

- 仅在任务书要求时编码。
- 相关 lint、build、test、governance 由任务书或 C0 明确要求后执行。
- 有可复现的运行和验证说明。
- 上游 Key、个人信息和成本数据不泄漏。

## Demo 放行

- 海底捞三里屯黄金路径 10—15 分钟可顺畅讲解。
- 关键 Tab、表单、状态、生成、额度和导出可操作或明确为 Mock。
- 1440×900 无关键裁切；参考图任务使用同尺寸证据。
- P0/P1/P2 均有结论，不能以“结构接近”代替验收。

## Gate

- T0：治理、岗位、共同记忆、合同骨架齐全。
- T1：领域和状态机冻结。
- D1：老板 Demo 通过。
- M1：商业 MVP 通过。
- P1：真实媒体生产通过。
