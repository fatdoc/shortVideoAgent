# MVP Scope

## 唯一纵向场景

本地单用户完成一条 30 秒 9:16 餐饮探店获客视频：

```text
对话收集商家信息
-> CreativeBrief
-> 标题/钩子/脚本
-> 6-10 个分镜
-> 画板调整
-> Mock/真实图片与视频 Provider
-> FireRed AI 粗剪
-> 自然语言修改
-> 1080x1920 MP4 导出
```

## 必须包含

- 小白对话和专业画板操作同一个项目。
- 城市、店名、地址、营业时间、人均、优惠、卖点、目标人群、平台、CTA 等本地生活字段。
- 全 AI、真人实拍、混合素材三种策略；生成素材必须标源。
- Mock Provider 在无 API Key 下跑完整闭环。
- 统一任务状态、失败重试、取消、成本字段和进度事件。
- FireRed 不可用时明确降级；原始素材和旧版本不被覆盖。

## 本轮不做

- 完整产品 UI、对话 Agent、画板节点和剪辑时间线。
- 真实收费模型调用或高成本视频生成。
- 大型 FireRed 模型/资源下载。
- 多租户、支付、会员、企业权限、云集群、移动端、自动发布。
- SaaS 部署和 GPU 调度。

## MVP 完成定义

只有当演示项目能够重启恢复，并在 Mock 模式下从 Brief 走到可播放 MP4，且同一数据在对话/画板/剪辑页保持一致，才算 MVP 完成。单独的 UI 原型、脚本 JSON、健康检查或构建通过都不等于 MVP 完成。
