## 一、对话上下文摘要

### 1.1 用户目标（2026-07-19 ~ 2026-07-20）

用户希望 StoryCanvas AI 实现如下端到端流程：

```text
输入一句视频需求
→ 大模型生成：脚本 + 分镜 + 人物/场景参考图
→ 打开无限画板，支持人工微调（改提示词、换图、锁定镜头）
→ 逐镜生成视频片段（画面可衔接、连成一体）
→ 调用 FireRed AI 剪辑：把多个约 15 秒片段粗剪成约 60 秒长视频
→ 后续可继续加字幕、配音、音乐、自然语言修改并导出
```

### 1.2 模型配置要求（用户明确指定）

| 能力 | 模型/供应商 | 说明 |
| --- | --- | --- |
| 大语言模型 | OpenAI 兼容接口 | baseUrl 可指向任意兼容服务 |
| 图片生成（主） | gpt-image-2 | 通过 OpenAI 标准接口 |
| 图片生成（备） | Seedream | 火山引擎 `volcengine` 供应商 |
| 视频生成 | Seedance | 火山引擎 `volcengine` 供应商 |

### 1.3 已确认的产品决策

1. **双图片模型分工**：默认 gpt-image-2 为主力、Seedream 为备用/可切换；画板上每个镜头可单独换模型。不采用「人物固定 A、场景固定 B」的硬分工。
2. **先 API 后 UI**：对话页和画板界面放在基础设施（数据层、任务中心、Provider）之后，先用接口验证全流程。
3. **60 秒成片拆分**：建议「5 镜 × 12 秒（Seedance 1.5-Pro，1080p）」或「4 镜 × 15 秒（Seedance 2.0，720p）」；配置文件默认前者，画板可改。

### 1.4 Git 与提交状态（2026-07-20）

- 本地提交 `77b8c24`：仅包含 `.gitmodules` 与 `upstream/FireRed-OpenStoryline` 子模块。

- **未推送**：仓库当前远程为上游 Toonflow（`upstream-toonflow`），无用户自有 origin；用户选择暂不推送。
- **未纳入该提交的内容**（仍留在工作区）：OpenStoryline Adapter、阶段 0 文档、`.env.example`、`README.md` 等改动。

### 1.5 执行指令

用户于 2026-07-20 要求按照本文档继续开发。阶段 1（模型配置层）和阶段 2（统一数据层）均已完成并通过测试，当前执行点切换到阶段 3（任务中心 + Provider）。

## 三、代码现状审计（影响后续开发）

### 3.1 供应商机制

Toonflow 已有可编程供应商体系：

- 模板目录：`data/vendor/*.ts`
- 运行时加载：`src/utils/vendor.ts` + `src/utils/vm.ts`
- 数据库表：`o_vendorConfig`（`inputValues`、`models`、`enable`）
- 统一调用入口：`src/utils/ai.ts`（`Ai.Text` / `Ai.Image` / `Ai.Video`）
- Agent 模型绑定：`o_agentDeploy`（格式 `vendorId:modelName`，如 `openai:gpt-5.2`）

### 3.2 三类模型的现成程度

| 模型 | 供应商文件 | 现状 |
| --- | --- | --- |
| OpenAI 兼容 LLM | `data/vendor/openai.ts` | `textRequest` 已实现 |
| gpt-image-2 | `data/vendor/openai.ts` | 已完成文生图与参考图编辑 Adapter |
| gpt-image-2（备选路径） | `data/vendor/grsai.ts`、`atlascloud.ts` | 已有完整实现，可作参考 |
| Seedream | `data/vendor/volcengine.ts` | 已内置 Seedream 3.0~5.0，`imageRequest` 完整 |
| Seedance | `data/vendor/volcengine.ts` | 已内置 Seedance 1.0~2.0，`videoRequest` 完整 |

### 3.3 Seedance 时长硬约束

单片段时长上限（来自 `volcengine.ts` 配置）：

- **Seedance 2.0**：4~15 秒，480p/720p
- **Seedance 1.5-Pro**：4~12 秒，480p/720p/1080p

因此「60 秒 = 4×15 秒」与「1080p 高清」不能同时作为默认策略，需在配置与 UI 中明确取舍。

### 3.4 片段衔接方案（阶段 6 采用）

1. **尾帧接首帧**：第 N+1 镜生成时，抽取第 N 镜视频最后一帧作为 Seedance 首帧参考。
2. **参考图一致性**：阶段 4 生成的人物/场景参考图，在图片与视频生成时作为 `multiReference` 传入。
3. **提示词与分镜锁定**：画板微调后的 `imagePrompt` / `videoPrompt` 写回数据库，重生成只影响该镜头。

## 四、模型配置文件设计（阶段 1 已完成）

### 4.1 原则

- **密钥进 `.env`**，配置文件只存「角色 → 模型」映射。
- API Key 不进入渲染进程、SQLite 明文、日志或 Git（见 `PROVIDER_GUIDE.md`）。
- 复用现有 `o_vendorConfig` + `o_agentDeploy`，不另造一套供应商系统。

### 4.2 建议文件结构

```jsonc
// config/models.json（示例，实际需 Zod 校验）
{
  "llm": {
    "vendor": "openai",
    "model": "gpt-5.2",
    "baseUrlEnv": "LLM_BASE_URL",
    "apiKeyEnv": "LLM_API_KEY"
  },
  "image": {
    "primary": {
      "vendor": "openai",
      "model": "gpt-image-2",
      "apiKeyEnv": "OPENAI_API_KEY"
    },
    "fallback": {
      "vendor": "volcengine",
      "model": "doubao-seedream-4-5-251128",
      "apiKeyEnv": "ARK_API_KEY"
    }
  },
  "video": {
    "vendor": "volcengine",
    "model": "doubao-seedance-1-5-pro-251215",
    "apiKeyEnv": "ARK_API_KEY"
  }
}
```

### 4.3 环境变量（`.env.example` 扩展）

```bash
# LLM（OpenAI 兼容）
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=

# OpenAI 图片（gpt-image-2）
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.openai.com/v1

# 火山引擎（Seedream / Seedance）
ARK_API_KEY=
ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3

# FireRed（已有）
OPENSTORYLINE_BASE_URL=http://127.0.0.1:7860
OPENSTORYLINE_MCP_URL=http://127.0.0.1:8001/mcp
OPENSTORYLINE_TIMEOUT_MS=2000
```

### 4.4 阶段 1 交付物清单

| 文件/脚本 | 说明 |
| --- | --- |
| `config/models.json` | 默认模型映射 |
| `src/config/models.schema.ts` | Zod Schema |

| `.env.example` | 补齐上述变量 |

## 五、分阶段开发计划

### 总览

| 阶段 | 名称 | 主要产出 | 验收标准 |
| --- | --- | --- | --- |
| **1（已完成）** | 模型配置层 | 见 §4.4 | `models:doctor` 通过；Key 不进入新增配置、SQLite 或日志 |
| **2（已完成）** | 统一数据层 | `sc_*` Migration + Zod 领域 Schema | 17/17 测试通过；Migration 可回滚；未改动 `o_*` 表结构 |
| **3** | 任务中心 + Provider | Mock 三件套 + 统一任务 SSE | Mock 模式跑通全流程；重启可恢复任务 |
| **4** | 需求 → 脚本 → 分镜 → 图片 | Brief / 脚本 / 6~10 分镜 / 参考图+分镜图 API | 一句需求 → 脚本 JSON + 每镜 9:16 图 |
| **5** | 画板人工微调 | Toonflow-web 固定 + 分镜节点 UI | 画板改动写回 DB；单镜重生成不影响其他镜 |
| **6** | 视频片段生成 | 逐镜 Seedance + 衔接策略 | 全部分镜有片段；相邻画面自然衔接 |
| **7** | FireRed AI 剪辑 | Session/素材/命令 Adapter | 导出 1080×1920 MP4；旧版本不被覆盖 |
| **8** | 端到端验收 | 文档 + 演示项目 | Mock 与真实两种模式均可走通 |

**顺序约束**：阶段 1~3 是地基，4~7 是用户流程本体；没有任务中心和数据层，视频生成失败无法断点续跑。

### 阶段 3：任务中心 + Provider 接口

依据 `PROVIDER_GUIDE.md`：

```ts
interface TextModelProvider {
  generateCreativeBrief(input: unknown): Promise<CreativeBrief>;
  generateScript(input: unknown): Promise<ScriptVersion>;
  generateStoryboard(input: unknown): Promise<Shot[]>;
  reviseContent(input: unknown): Promise<unknown>;
}

interface VideoModelProvider {
  textToVideo(input: VideoGenerationInput): Promise<GenerationResult>;
  imageToVideo(input: VideoGenerationInput): Promise<GenerationResult>;
  getTaskStatus(taskId: string): Promise<GenerationResult>;
  cancelTask?(taskId: string): Promise<void>;
}
```

- `MockTextProvider`：固定餐饮探店 Brief、脚本、8 个分镜
- `MockImageProvider`：9:16 占位图
- `MockVideoProvider`：FFmpeg 短静态片段 + 模拟进度
- 统一：`idempotencyKey`、重试、取消、成本字段、SSE 进度

---

### 阶段 4：需求 → 脚本 → 分镜 → 图片

**MVP 纵向场景**（`MVP_SCOPE.md`）：30 秒 9:16 餐饮探店获客视频。

流程：

```text
对话收集商家信息 → CreativeBrief
→ 标题 / 钩子 / 脚本
→ 6~10 个分镜（Scene + Shot）
→ 先生成人物/场景参考图（o_assets + o_image）
→ 再用参考图批量生成分镜图（o_storyboard）
```

可复用模块：

- `src/agents/scriptAgent`、`src/agents/productionAgent`
- `src/socket/routes/*`
- `data/skills/` 下分镜、资产提取 Skill

---

### 阶段 5：画板人工微调

**前置**：固定 `upstream/Toonflow-web` 或 fork，构建产物复制到 `data/web`（不得直接改压缩后的 `data/web`）。

画板能力：

- 分镜节点展示：提示词、预览图、时长、锁定状态
- 单镜：改 `imagePrompt` / `videoPrompt`、切换图片模型、重生成、锁定
- 写回 `sc_shot_metadata` + `o_storyboard`

---

### 阶段 6：视频片段生成

- 调用：`Ai.Video('volcengine:doubao-seedance-1-5-pro-251215')` 或配置中的 video 模型
- 输入：分镜图 + 视频提示词（可复用 `o_prompt` 中 `videoPromptGeneration` Skill 逻辑）
- 输出：每镜一个 `o_video` / `sc_media_assets` 记录
- 衔接：上一镜尾帧 → 下一镜首帧（Seedance `startFrameOptional`）

---

### 阶段 7：FireRed AI 剪辑

依据 `INTEGRATION_PLAN.md` 扩展 OpenStoryline Adapter：

| API | 状态 |
| --- | --- |
| `GET /api/integrations/openstoryline/health` | 已完成 |
| `POST /api/edit-sessions` | 待开发 |
| `POST /api/edit-sessions/:id/assets` | 待开发 |
| `POST /api/edit-sessions/:id/commands` | 待开发 |
| `POST /api/edit-sessions/:id/render-preview` | 待开发 |
| `POST /api/edit-sessions/:id/export` | 待开发 |
| `GET /api/tasks/:id/events`（SSE） | 待开发 |

目标：上传 N 个 ~15 秒片段 → 自然语言指令粗剪 → 约 60 秒预览 → 导出 MP4。

FireRed 完整剪辑还需其 LLM/VLM 六组配置（model、base_url、api_key 各两组）。
