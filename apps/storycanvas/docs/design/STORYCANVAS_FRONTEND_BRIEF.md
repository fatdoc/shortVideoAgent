# StoryCanvas 导演画布前端设计基线

## 视觉真相

- Image 2 原型：`docs/design/storycanvas-canvas-image2.png`
- 选定方向：第 2 张“导演画布”
- 目标视口：1440 × 1024 桌面端

## 视觉命题

一张安静的导演灯光桌：暖白画布、墨黑信息、单一钴蓝强调，用真实影像和细线关系呈现分镜逻辑。

## 内容计划

1. 左侧导航和脚本大纲，用于定位项目与镜头章节。
2. 中央五镜空间画布，用于选择、拖动、查看分镜及参考图关系。
3. 右侧镜头检查器，用于编辑图片/视频提示词、模型、时长和锁定状态。
4. 底部任务状态条，用于显示时长、镜头数、生成进度与撤销/重做。

## 交互命题

- 选择镜头时，画布节点和右侧检查器共享快速布局过渡。
- 拖动镜头节点与缩放画布形成导演桌的空间感。
- 重新生成后，底部进度条、节点状态和完成通知同步变化。
