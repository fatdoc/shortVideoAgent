## 一、项目定位

StoryCanvas AI 是面向探店、本地生活、商家获客、产品种草、旅行 Vlog 和生活方式创作者的一站式 AI 短视频创作平台。

目标工作流：

```text
对话描述视频需求
→ 生成创意、标题、钩子和脚本
→ 拆分场景与分镜
→ 在无限画板中调整镜头
→ 生成分镜图片和视频片段
→ FireRed AI 理解素材并粗剪
→ 添加字幕、配音、音乐和转场
→ 通过自然语言继续修改
→ 导出完整短视频
```

项目以 Toonflow 作为主应用，以 FireRed-OpenStoryline 作为独立 AI 剪辑服务，二者通过 Adapter 和统一 API 连接。

### 8. 密钥隔离、供应商种子与 Agent 绑定

- `yarn models:seed` 已成功启用 `openai`、`volcengine`；
- 16 个文本 Agent 已绑定到 `openai:gpt-5.2`；
- SQLite 只保存模型、URL 和环境变量名，不写入环境变量中的 API Key 值；
- 调用模型时，`src/utils/ai.ts` 才按能力和模型从环境变量注入密钥；
- 同一 `openai` 供应商可分别使用 `LLM_*` 和 `OPENAI_*` 两组地址与密钥；
- `yarn models:doctor` 默认是安全 dry-run，未配置密钥时明确跳过联网，不产生费用。

### 9. OpenAI `gpt-image-2` 图片 Adapter

`data/vendor/openai.ts` 已补全图片生成能力：

- 文生图调用 `/v1/images/generations`；
- 单图/多图参考调用 `/v1/images/edits`；
- 支持最多 16 张 PNG、JPEG、WebP Data URL 参考图；
- 按画面比例映射竖图、横图和方图尺寸；
- 返回 Base64 或临时 URL 时统一转换为 Toonflow 可保存结果；
- 日志不输出 API Key 和图片 Base64。

实现依据 OpenAI 官方 `gpt-image-2` 模型和 Image API 契约。自动测试使用本地模拟响应，没有调用收费接口。

## 八、项目运行配置

模型配置：

```bash
export LLM_BASE_URL=https://api.openai.com/v1
export LLM_API_KEY=
export OPENAI_BASE_URL=https://api.openai.com/v1
export OPENAI_API_KEY=
export ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
export ARK_API_KEY=

yarn models:seed
yarn models:doctor
# 配置 Key 后只做鉴权/模型可用性联网检查：
yarn models:doctor --live --require-keys
```

默认 `models:doctor` 不联网、不调用图片或视频生成。

数据库 Migration：

```bash
yarn db:migrate
yarn db:status
# 仅在明确需要回滚开发库时执行：
yarn db:rollback
```

Toonflow 到 FireRed 的环境变量：

```bash
export OPENSTORYLINE_BASE_URL=http://127.0.0.1:7860
export OPENSTORYLINE_MCP_URL=http://127.0.0.1:8001/mcp
export OPENSTORYLINE_TIMEOUT_MS=2000
```

Toonflow 开发启动：

```bash
nvm use 24
yarn install --frozen-lockfile
yarn lint
yarn test
yarn build
NODE_ENV=dev yarn dev
```

FireRed Web 最小启动：

```bash
cd upstream/FireRed-OpenStoryline
PYTHONPATH=src .venv/bin/python -m uvicorn agent_fastapi:app \
  --host 127.0.0.1 \
  --port 7860
```
